## Phase 4 Overview

Phase 4 is where you develop the **thinking ability** that separates engineers from script writers. DSA is not about memorising solutions — it is about building a mental framework for decomposing any problem into smaller, solvable pieces and choosing the most efficient tool for each situation.

| DSA Topic | Direct AI/ML Library Dependency | Interview Relevance |
|-----------|--------------------------------|--------------------|
| Big O Notation | NumPy vectorisation vs loop: O(n) vs O(n²) | Asked in every FAANG + top ML engineer interview |
| Arrays & Matrices | NumPy ndarray internals, tensor shapes in PyTorch | Foundation of all matrix operations in deep learning |
| Stacks & Queues | DFS in graph neural nets, BFS for layer-wise training | Core data structures for algorithm design rounds |
| Recursion | Recursive tree traversal in decision trees, backtracking | Tests logical thinking depth in interviews |
| Sorting Algorithms | Merge sort used in Pandas `sort_values` internals | Pattern recognition, divide & conquer thinking |
| Binary Search | Hyperparameter search, threshold optimisation | O(log n) thinking — critical for efficiency |
| Trees & Graphs | Decision trees, GNNs, knowledge graphs, DAG pipelines | Tree traversal asked in 80% of ML interviews |
| Hash Maps | Feature indexing, NLP vocabulary, caching layers | O(1) lookup — used everywhere in production ML |

---

## Learning Outcomes

- Analyse and compute time and space complexity using Big O notation
- Implement arrays, matrices, and all core data structures from scratch using OOP
- Write recursive solutions and convert them to iterative equivalents
- Implement and analyse bubble, selection, insertion, merge, and quick sort
- Apply binary search and its variants to real problem patterns
- Build and traverse binary trees and graphs (BFS, DFS)
- Use hash maps to solve lookup, frequency, and grouping problems efficiently
- Connect every DSA concept to its NumPy/Pandas/PyTorch equivalent
- Solve LeetCode Easy problems independently and Medium problems with guidance
